## 🧩 Trae 网关补齐 `/v1/responses`

- Trae 分区现在支持 Responses API：只认 `/v1/responses` 的客户端（Codex 等）把 baseURL 指向 `trae-*` 命名空间即可，不用再退回 chat 形态。
- 出站由网关翻译成 chat（`llm_utils_chat` 只认 chat），选号 / 换号 / 冷却 / 粘性 / 记账与 `/v1/chat/completions` 完全同一条链路，没有第二套中继。
- 统一网关不再对 `trae-*` 返回 `501 endpoint_not_supported_for_namespace`，管理面那条「Trae 不支持 Responses」的错误示例也已删除。
- 三条产品线现在都支持 `/v1/chat/completions`、`/v1/messages`、`/v1/responses`，差别只剩错误体形状。

## 🖼 图片：能透传就透传，必须转换才转换，绝不静默丢弃

- `/v1/messages`（WorkBuddy / Trae）默认仍不转发图片 —— 上游是否接受结构化 `image_url` parts 尚未实测，贸然打开只是把「静默丢图」换成「上游 400」。
- 但被丢弃时会在用户文本里留下「已移除 N 张图片」，不再让模型凭空回答一个看不见图的问题。
- 想自己试带图：设 `BUDDY_SWITCH_ANTHROPIC_FORWARD_IMAGES=1`，网关改走带图分支。
- Qoder 侧的图片归一化保留 `detail` 档位（`low` / `high` / `auto`）：归一化只该改形态，不该顺手摘掉决定分辨率与 token 的语义字段。

## 🛠 其他

- 侧栏导航项改为静态 `className` —— 修掉上一版在 GitHub Pages 与桌面端出现的「图标一行、文字一行、徽章满宽」塌陷（Radix `Slot` 会把函数式 `className` 串成字符串）。
- 模型限流探测：结果写入跨重启台账（`probe_results.json`），显式格清单与「账号 × 模型」两轴选择互斥；原型新增 CDP 实测脚本 `docs/prototype/verify-model-probe.mjs`。
- 版本号统一为 2026.10.230947（全部载体校验通过）。
